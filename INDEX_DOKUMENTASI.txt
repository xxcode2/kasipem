🔑 TOPIK PENTING

Sistem Penomoran Surat
├─ Lihat: SPESIFIKASI_TEKNIS_TEMPLATE.md → Sistem Penomoran Surat
├─ Format: [URUT]/[KOMUNITERING]/[TIPE]/[TAHUN]
├─ Tipe: Pem (Pemerintah), Ks (Keterangan Sosial), Manual
├─ Counter: Auto-increment per jenis per tahun
└─ Database: Table `surat_counters` (id, template_id, year, last_counter)

Signature Variants
├─ Lihat: SPESIFIKASI_TEKNIS_TEMPLATE.md → Signature Roles
├─ Variant 1: A.n Kepala Desa (Atas Nama) - Sekretaris Desa sign
├─ Variant 2: Langsung dari Kepala Desa - Kepala Desa sign
└─ Variant 3: Co-signatory - Ketua RW + Sekretaris Desa (SKM)

Format Tanggal
├─ Lihat: SPESIFIKASI_TEKNIS_TEMPLATE.md → Date Format
├─ TTL: DD-MM-YYYY (12-05-1994)
├─ Surat: DD MMMM YYYY (06 Juli 2026)
└─ Bulan: Januari, Februari, Maret, ... (Indonesian)

Field Validasi
├─ Lihat: SPESIFIKASI_TEKNIS_TEMPLATE.md → Validasi Data
├─ NIK: 16 digit
├─ Tanggal: Valid date format
├─ RT/RW: Format regex `^RT \d{3} RW \d{3}$`
└─ Enum: Validasi agama, status, sifat surat
