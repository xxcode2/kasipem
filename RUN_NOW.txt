================================================================================
🔧 TROUBLESHOOTING CEPAT
================================================================================

Jika ada error:

1. Pastikan Node.js sudah terinstall:
   node --version
   (harus v18 atau lebih tinggi)

2. Jika port 3000 sudah dipakai, gunakan port lain:
   npm run dev -- -p 3001
   Kemudian buka: http://localhost:3001

3. Jika masih error, hapus folder .next dan coba lagi:
   rm -r .next
   npm run dev
